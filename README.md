# aditya0212jain.github.io

Personal website of Aditya Jain, served by GitHub Pages at https://aditya0212jain.github.io.

Plain static HTML/CSS with no build step:

- `index.html`, `about.html`, `books.html`, `contact.html`: pages
- `style.css`: shared styles (light/dark theme via CSS variables)
- `theme.js`: dark-mode toggle and footer year
- `files/`, `resume.pdf`, `btp_thesis.pdf`: linked documents

To preview locally: `python3 -m http.server` and open http://localhost:8000.
